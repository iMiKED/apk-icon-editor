# APK Icon Editor Reborn v3.0.0-beta4.1

This hotfix prerelease corrects beta4 theme regressions while keeping the Windows-only theme work available on Windows.

## Highlights

- Restored native macOS and Linux window chrome, title bars, menu bars, window shape and platform theming.
- Kept the beta4 frameless title bar, Windows accent border and custom dark/light theme styling Windows-only.
- Fixed switching from Dark to Light theme on Windows so native light palette colors are restored correctly.

## Notes

- macOS artifacts are still unsigned and not notarized, so Gatekeeper can still warn that the developer cannot be verified.
- The release keeps the same adaptive icon, localization, split-resource preview and icon-size preset functionality introduced in beta4.
