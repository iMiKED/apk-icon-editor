# APK Icon Editor Reborn v3.0.0-beta3

This beta continues the adaptive XML icon work and renames the project branding to **APK Icon Editor Reborn**.

## Highlights

- Added simple `resources.arsc` reference alias resolution for adaptive XML launcher icons.
- Added `resources.arsc` scalar value resolution for table-only colors and file-backed drawable/mipmap resources.
- Added read-only split APK resource discovery for adaptive XML icon previews when compatible split APKs are stored next to `base.apk`.
- Improved adaptive icon diagnostics by showing base/split resource sources, split discovery summaries, and inline XML/vector layer metadata.
- Added a clear preview-only/read-only policy for adaptive icons that use split APK resources; split APK replacement and repacking are intentionally blocked.
- Optimized split APK discovery to run only when the decoded base manifest declares split resource metadata, and then only decode split-like sibling APK filenames.
- Preserved direct XML resource candidates when default values aliases exist for the same launcher icon.
- Fixed Snapseed-style adaptive icons that combine direct adaptive XML, values aliases, vector foregrounds, color XML backgrounds, and percent insets.
- Added adaptive XML rendering support for drawable color XML files and percent-based inset drawables.
- Renamed application branding and package/binary names to APK Icon Editor Reborn.

## Validation

- Built locally on Windows with Qt 6.8 and Visual Studio 2022 Build Tools.
- Verified that the Windows binary is produced as `apk-icon-editor-reborn.exe`.
