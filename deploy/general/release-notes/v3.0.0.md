# APK Icon Editor Reborn v3.0.0

The first non-beta Reborn release brings the adaptive icon, resource alias, localization, and platform improvements developed throughout the 3.0 beta series.

## Highlights

- Adaptive XML and legacy bitmap launcher icons are separate, expandable groups. Adaptive previews are selected by default; legacy alternatives remain available without overriding the adaptive image.
- Launcher branch and Adaptive/Legacy group headings show small previews of their own icons, updated immediately after replacement.
- Fixed incorrect launcher previews when the legacy icon is a placeholder but the adaptive XML contains the actual application artwork.
- Application icon and application roundIcon are shown separately, before launcher activity and activity-alias entries.
- The replacement dialog shows the current icon, imported foreground, density count, and an explicit **Also update legacy bitmap alternatives** checkbox, unchecked by default.
- Unchanged bitmap resources are no longer rewritten during APK packing.
- Update checks correctly rank the final 3.0.0 release above earlier 3.0.0 beta versions.
- Includes adaptive foreground/background composition, vector and WebP rendering, resources.arsc aliases, read-only split resource discovery, and standalone XML drawable preview/export.
- Includes configurable Android/Android TV size presets, themed monochrome previews, the Reborn Crowdin localization, Windows theme/accent improvements, and native macOS/Linux window behavior.
- Includes the patched Apktool `v3.0.3-11-79b63384-SNAPSHOT` build for decoding NUL-only resource strings.
- Bundles the Qt WebP plugin on Windows/macOS and declares the matching runtime dependency in DEB/RPM packages.

## Write-back

Write-back is the resource change made before Apktool rebuilds an APK. Adaptive replacement updates the foreground while preserving the background and monochrome layers. Bitmap foregrounds are replaced in place; XML/vector foregrounds use generated bitmap resources referenced by the adaptive XML. Foregrounds that share a file with a legacy alternative are detached into a custom foreground so the legacy file is preserved.

Legacy alternatives change only when explicitly selected for editing or when **Also update legacy bitmap alternatives** is enabled during adaptive replacement. The option scales the imported replacement to the existing legacy image sizes. Exporting an icon saves the selected representation; it does not edit the APK.

## Limitations

- Split APK resources remain preview/export-only. Editing and repacking complete split sets is not supported.
- Standalone XML/vector launcher icons support preview and export, but not replacement.
- Launcher masks and monochrome mode are preview options; they do not change the original APK resources.
- Rebuilt APKs require signing and may not install as updates over APKs signed by another key.
